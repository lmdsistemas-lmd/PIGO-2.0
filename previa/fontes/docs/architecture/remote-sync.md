# Remote Sync

O Remote Sync transporta dados autorizados do ERP para o ambiente analítico do P.I.G.O. Ele não define conceitos de negócio nem regras de relatório.

Dados sincronizados alimentam providers e catálogos. Identidade de instalação, credenciais e isolamento por tenant permanecem responsabilidades próprias do agente e das APIs de sincronização.
